# Creatup Engine 2 – Logic & Rules (DSA and Programming)

This package contains current frontend prototype logic used for role-oriented navigation and dashboard interactions, including the standalone Talent and Organization dashboard pages. It is not a fully integrated authentication or backend application.

## Run the prototype
1. Install Node.js.
2. In `frontend`, run `npm install`.
3. Run `npm run dev`.
4. Open the Vite URL and the dashboard pages as applicable (for standalone HTML, use `/user_index.html` and `/org_index.html`).

Search/filter/application actions and role-flow behavior should be treated as prototype behavior where not connected to backend services.
